# Lecture Transcript v4.0

تطبيق ويب قابل للتثبيت على Android لتفريغ المحاضرات بالإنجليزية والعربية مع إمكانية تصدير النص إلى Word.

## فتح التطبيق
https://engma8585.github.io/Lecture-Transcript-/

## طرق الاستخدام
1. **Whisper (مجاني ومحلي):** اختر التسجيل، ثم اختر النموذج متعدد اللغات. يعالج الصوت داخل المتصفح على أجزاء متتالية. قد يستغرق تفريغ التسجيلات الطويلة وقتًا كبيرًا، وتختلف الجودة حسب الجهاز والتسجيل. التبديل بين العربية والإنجليزية داخل الجملة الواحدة ليس مضمون الدقة.
2. **Gemini ضمن اشتراك Google AI Pro:** استخدم زر نسخ البرومبت وفتح Gemini، وارفع التسجيل داخل Gemini بنفسك. انسخ الناتج أو استورده للتطبيق، ثم صدّره إلى Word. **لا يستخدم هذا المسار Gemini API ولا يربط التطبيق مباشرة بحساب Gemini.**
3. **تنزيل النتائج:** DOCX وTXT، وSRT عند وجود توقيتات حقيقية من تفريغ Whisper.

## التثبيت على Android
افتح الموقع من Chrome، ثم القائمة ⋮ > Add to Home screen / Install app (حسب المتصفح). أُعدّ الموقع كتطبيق PWA، وليس ملف APK أصليًا.

## الخصوصية والتكلفة
- لا توجد مفاتيح API أو فوترة إضافية ضمن التطبيق.
- الصوت في وضع Whisper يُعالج محليًا في المتصفح، وتُنزل نماذج Whisper من مصادرها العامة.
- عند استخدام Gemini يتم رفع التسجيل إلى Google في تطبيق Gemini، وتطبق شروط حسابك وحدود الاستخدام.
- يُحفظ التقدم محليًا في متصفحك عند توفر مساحة؛ أنزِل نسخة Word للاحتفاظ بنسخة احتياطية.
- لا تغلق الصفحة أثناء التفريغ المحلي، وتجربة أداء الساعة الكاملة على الموبايل مطلوبة.

## بنية المشروع
- `index.html`: واجهة التطبيق والمنطق المحلي وتصدير Word
- `manifest.webmanifest`: إعدادات تثبيت PWA
- `sw.js`: التخزين المؤقت لملفات الواجهة فقط
- `icon-192.png`, `icon-512.png`: أيقونات التطبيق
